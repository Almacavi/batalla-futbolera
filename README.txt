BATALLA FUTBOLERA — WEB OFICIAL (PAQUETE INICIAL)

CONTENIDO
- index.html: página de presentación.
- juego.html: simulador existente con la base de 2.786 jugadores integrada.
- assets/logo-batalla-futbolera.png: logo.

PRUEBA LOCAL
Abre index.html en el navegador. Para la prueba, la web y el juego funcionan como archivos estáticos.

PUBLICAR GRATIS CON GITHUB PAGES
1. Crea/inicia sesión en https://github.com/
2. Crea un repositorio público, por ejemplo: batalla-futbolera
3. Sube index.html, juego.html, README.txt y la carpeta assets (no subas solo el ZIP).
4. En el repositorio entra en Settings → Pages.
5. En “Build and deployment”, elige “Deploy from a branch”, rama main y carpeta /(root), y guarda.
6. GitHub publicará una URL parecida a https://TUUSUARIO.github.io/batalla-futbolera/ (puede tardar unos minutos).
Documentación oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

DONACIONES PAYPAL
- La web no cobra ni almacena datos bancarios.
- Ve a https://www.paypal.com/buttons/ y comprueba las opciones de donación disponibles para tu cuenta, o crea tu enlace PayPal.Me desde PayPal.
- En la página publicada, pulsa “DONAR CON PAYPAL” y pega el enlace público de PayPal. El enlace se guarda únicamente en el navegador usado para configurarlo; para dejarlo preconfigurado para todos los visitantes, hay que insertar el enlace definitivo en el archivo index.html y volver a publicar.
- No compartas contraseña ni datos bancarios.

IMPORTANTE
Esta carpeta es un paquete estático listo para publicar, no una web que ya esté alojada. Aún hay que subirla a un proveedor de alojamiento. El dominio propio es opcional y normalmente se paga aparte.
